# Test Scope – QMS Event (Deviation) Module

## Objective
To validate the functionality, usability, and data integrity of the Event (Deviation) module in a Quality Management System (QMS).

## In Scope
- Event creation and form validations
- Mandatory field checks
- Workflow navigation and status handling
- Role-based access behavior
- UI and field-level validations
- AI Agent / AI Co-Pilot panel visibility and interaction
- Error messages and system responses

## Out of Scope
- Login and authentication functionality
- Other QMS modules (CAPA, Complaints, Recall, etc.)
- Backend and database validation

## Test Artifacts
- Manual test cases documented in Excel
- Test cases include:
  - Positive scenarios
  - Negative scenarios
  - Boundary value scenarios
  - UI validations
  - Workflow validations
