# QMS Event (Deviation) – Manual Testing Documentation

## Overview
This repository contains manual test case documentation for the **Event (Deviation) module** of a Quality Management System (QMS).  
The work was performed as part of a real-world testing assignment during an interview process.

## Module Covered
- Event (Deviation) Management

## Test Case Details
- Total Test Cases: 100+
- Documentation Tool: Excel
- Test Types Covered:
  - Functional Testing
  - Negative Testing
  - Boundary Value Testing
  - UI Testing
  - Validation Testing
  - Workflow Testing

## Key Areas Validated
- Event creation and form behavior
- Mandatory and optional field validations
- Workflow status navigation
- Locked workflow behavior
- AI Agent / AI Co-Pilot panel accessibility
- Error handling and system messages
